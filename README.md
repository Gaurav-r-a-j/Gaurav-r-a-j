# @Gaurav-r-a-j

**Full-stack developer and product builder working with JavaScript, TypeScript, React, and Next.js. I build useful software, open-source tools, and products that solve real problems.**

### About me

I enjoy taking ideas from **concept → design → code → production**.

Most of my work revolves around modern web development, developer tooling, UI systems, performance-focused utilities, SaaS products, and AI-powered applications. I like building things that are simple to use, technically solid, and actually useful.

My open-source work includes tools for image optimization, UI feedback, developer profiles, and other utilities designed to remove friction from everyday development.

Beyond open source, I've worked on products involving **AI, marketplaces, rental platforms, exam preparation, customer support, analytics, developer tools, cloud infrastructure, and automation**.

I care about **good UX, performance, accessibility, maintainable code, and keeping software simple**.

### What I'm working on

Currently exploring and building across:
